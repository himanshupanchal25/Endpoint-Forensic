# Endpoint Forensic

## Overview 
This project focus on endpoint forensic and investigation analysis of digital artificats and evidence collected from suspicious and compromised system.

## Objectives
- Anlayze windows and linux endpoint 
- identify suspicious user bheaviour,user activity,processes and executables
- Examine filesystem and registry hives artificats
- identify indicators of compromise (IOCs)
- Identify c2 and communication channels
- Build an evidence-based forensic timeline and map findings to MITRE attack timeline
- Document investigation findings and prepare forensic reports

## Investigation Workflow

- Evidence Acquisition
- Preservation and Backup
- Artifacts Extraction
- Analysis of Artifacts
- Timeline Construction
- IOc and C2 identification
- MITRE Attack Mapping
- Investigation Report

## Tools Used
- FTK Imager for disk and evidence acquisition
- Autopsy for digital forensics analysis 
- Kape for artifacts collection and rapid triage
- Registry Explorer for Windows Registry analysis
- RegRipper for registry artifact extraction and readability
- Volatility3 for memory dump forensics
- Zeek and Wireshark for packet and network analysis

## Conclusion

The aim of this project is to collect and correlate evidence to reconstruct the endpoint activity and establish an investigative timeline across filesystem memory,registry,event logs and network artifacts.
